# JARVIS V1 — Voice Foundation

This is the first modular build of the Jarvis project.

## Current flow

Microphone → Google Speech Recognition → Wake Word → Command Handler → pyttsx3

## Files

- `main.py` — application controller
- `core/speech.py` — speech-to-text layer
- `core/tts.py` — text-to-speech layer
- `core/wake_word.py` — wake-word detection
- `config/` — future configuration
- `tools/` — future browser/computer/music/system tools

## Dependencies

Uses the packages already present in the project environment:

- SpeechRecognition
- PyAudio
- pyttsx3

No new package is required for V1.
